# 当前验收状态

未达到全量交付标准。原生后端未修改。

## 已验证
- 前端 24 项本地自动化测试通过，TypeScript 与 Vite 生产构建通过。
- MCP 中继 5 项本地 fixture 测试及 TypeScript 构建通过。
- 浏览器冒烟 12 项检查通过，含五种视口、配置编辑、横屏修复及模拟 REST 登录后的 busy 清理、密码清除、JWT 不回显。真实 REST 后端未验收；测试记录含预期不可达 dummy WS 错误。
- 构建仍提示主包大于 500KB、zod 注释优化警告，不影响构建成功。

## 会话与登录修复
- MCP DELETE 无响应时，最多等待 3 秒后尝试关闭旧客户端，避免无限阻塞切换；fake timer 回归已通过，远端销毁不保证成功。
- REST 登录成功清除 busy，避免面板永久禁用；浏览器模拟登录回归通过。
- 下载增加操作代次校验，取消后不应触发旧下载；尚缺独立浏览器下载取消回归。

## 本轮新增验证
- 官方 MCP SDK 通过两个本地 HTTP fixture 端点完成 12 次交替连接，验证工具、资源、提示词和 DELETE 清理；不是两台真实 PilotDeck 验收。
- 修复中继浏览器 OPTIONS 预检与 session 响应头暴露，新增允许/拒绝来源回归测试。
- 会话映射增加默认 1000 条上限与请求时过期清理，配置支持 maxSessions。尚无后台保活或完整托管会话保障。

## 实现范围与缺口
| 要求 | 当前状态 |
|---|---|
| 双业务通道 | 原生 Gateway 1.1 WS、官方 UI REST 面板与 MCP 客户端已集成；真实后端联调待验收 |
| 多实例 | 新增编辑删除、单条/批量 JSON 导入、记住选择、默认内存令牌；切换关闭旧连接和阻止旧结果更新；真实双实例全链路隔离待测 |
| 工作空间 | WS 列表详情及 UI REST 创建删除等高级参数操作，非完整官方桌面交互 |
| Agent | 会话/子代理与 REST 运行配置等接口，尚未完成全部 Agent 编辑体验 |
| 对话 | 历史、发送、原始事件流、停止、IME 修复、选择竞态修复；消息编辑删除、富内容及流式体验未完整对齐 |
| 任务 | cron 创建更新运行停止删除；不等于所有后台长任务队列功能 |
| 文件 | WS 元数据；UI REST 创建删除读写上传和项目 ZIP 下载；真实文件系统权限及大文件待测 |
| 记忆 | 官方 UI REST 高级参数操作已接入；清空等破坏操作需确认；真实功能待测 |
| 扩展/设置 | 技能 WS 与部分插件、配置 REST 接口；非全部官方设置体验 |
| 日志 | 会话与子代理记录可读，完整系统日志未完成 |
| MCP | 官方 SDK 工具列表调用、资源列表读取、提示词列表获取；未声明 sampling 能力，不自动采样；需用户介入的 sampling 尚未实现 |
| MCP 网关 | POST GET DELETE/SSE 透明中继和会话映射；不是服务端托管 SDK Client，自动保活、上游健康检测、自身鉴权尚不满足完整要求 |
| 自动重连 | WS 1/2/4 秒有限重连、不重放业务调用；长期网络恢复与数据重载待联调 |
| PWA | 应用壳缓存、安全区与触控样式，修复横屏重叠和误删同源其他缓存；实机安装离线待测 |
| 安全 | UI JWT 与原生 token 分离，REST 请求取消；网关须置于同源认证代理后，不得裸露公网 |
| 全版本兼容 | 仅以当前源码契约为依据，不能保证未来或所有版本 |
| 稳定性 | 未完成双真实实例切换 10+ 次、长时 MCP、大流式与实机压测 |
